# Pesticide Pollution in Soils of India

An evidence-based, wiki-style website on the *status, causes, consequences and solutions of pesticide pollution in Indian soils*.

🔗 *Live site:* https://karansingh-py.github.io/Pesticide-Pollution-Soil-India/

## What's inside
- Overview and key facts
- History timeline of pesticide use and regulation in India
- Causes: persistent legacy chemicals, banned products still in use, weak enforcement
- Scale of use, with charts and state-wise rankings
- Regional soil studies (northern India, Himalaya, south-west coast, Haryana, Tamil Nadu)
- Consequences for soil life, water, food and health, including the Kasaragod endosulfan case
- Law and governance, and solutions such as IPM and natural farming
- 17 cited sources from government records, ICAR, Supreme Court orders and peer-reviewed studies

## Built with
HTML, CSS and a little JavaScript. No build step, hosted on GitHub Pages.

## Run locally
Download the repository and open index.html in a browser.

## Note
This is an educational, public-awareness resource compiled from the sources listed on the site. It is not an official publication. Please verify figures against the original records before formal use.
